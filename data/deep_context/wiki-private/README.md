# Private Wiki

This is the **PRIVATE** version of the personal knowledge wiki — the source of truth.
It contains everything the shared wiki holds, plus full source pointers and sensitive
details that must never leave the owner's control: financial figures, medical information,
private contact info, candid assessments, and internal context.

**Never publish or commit this directory to any public (or shared-with-others) repository.**
The shared, publishable wiki lives in `wiki/` and is a redacted projection of this one.

It mirrors the shared wiki's category structure:

- `people/`
- `organizations/`
- `projects/`
- `positions/`
- `expertise/`
- `timeline/`

The `/wiki` skill writes full-detail articles here first, then derives the redacted
shared articles in `wiki/`.
